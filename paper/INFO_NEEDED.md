## Quick check before submitting

```bash
grep -c 'needsnum{' paper/main.tex    # 30 now; must be 0 before submission
grep -n 'AUTHORS' paper/main.tex      # nothing should remain
```

Then set `\revisionfalse` in the preamble for a clean copy without the blue and red
markup, and compile: `pdflatex main` → `biber main` → `pdflatex main` ×2.
